# herdr-toolkit

Personal customizations for the [Herdr](https://herdr.dev) desktop app.

## What's here

| Path | Installs to | What it does |
|---|---|---|
| `mods/claude-limits-status/` | `~/.config/herdr-app/mods/claude-limits-status/` | Herdr's bottom status bar (clone of `workspace-status` 0.1.16) plus Claude Code's model, usage limits and context window usage next to the agents count: `6 agents │ Opus 5.5 (medium) 17%/5h 3h35m 7%/7d 2d13h 42%/ctx`. Only the percentages are colored (green, yellow ≥ 60 %, red ≥ 85 %). Next to the branch it shows git stats for the focused terminal's folder, zero counts hidden: `⚔` conflicts, `●` staged, `✚` modified, `?` untracked, `↑`/`↓` ahead/behind upstream, `+A/−D` uncommitted lines, `stash N`, `REBASING`/`MERGING` (refreshed on focus change and every 6 s). Then the branch's pull request via `gh pr view`: `#123` (click opens it), CI `✓` pass / `✗` fail / `●` pending with its wall-clock time (earliest check start to latest finish; while running, time so far, refreshed every 10 s), `draft`/`merged`/`closed`, `approved`/`changes requested`; asked at most once a minute per branch, hidden when the branch has no PR or `gh` is missing. At the right, where Herdr shows the palette hint, prices: `BTC $63,175 +0.0%  ETH $1,786 +0.9%  Gold $3,677 −1.5%` (24 h change green / red) from CoinGecko's public `simple/price` API (gold is Tether Gold, one token per troy ounce), one GET every 2 min while the window is active, no key; click refreshes. `⌘⇧P` still opens the palette. |
| `mods/vnh-chrome/` | `~/.config/herdr-app/mods/vnh-chrome/` | Clone of Herdr's `workspace-chrome` (0.1.16). The sidebar's top row is a JetBrains style branch button instead of the logo, search (`⌘P`) and sidebar toggle (`⌘B`): `⑂ develop ▾` for the repo of the focused work folder (the active space's last terminal folder). A click opens `vnh-git-menu` flush with its left edge. It reads the branch with one small git call, at once when the folder changes or a git action ran from the popup, else every 10 s while the window is active. Outside a repo the row is empty. |
| `mods/vnh-git-menu/` | `~/.config/herdr-app/mods/vnh-git-menu/` | The branch popup: a search box over actions and branches; Update Project (`git pull --ff-only`), Commit (opens the Changes panel), Push (as `⌘\`, branch and tags), Incoming and Outgoing Commits (`↓N ↑M`; a click fetches), New Branch (`git switch -c`), Checkout Tag or Revision (`git checkout`); then Local branches (current marked, favorites starred and first, upstream on the right) and Remote ones (folded until opened or searched; one checks out tracking it). Each branch's `›` (or `→`) shows its actions under it: New Branch from it (`git switch -c <name> <it>`), Update (the current one `git pull --ff-only`, another `git fetch <remote> <up>:<it>`, fast-forward only), Push (branch and tags), Rename (`git branch -m`), Add to / Remove from Favorites, Show History (`git log --graph` in a new tab); a remote branch has Checkout, New Branch from it, Show History. `↑`/`↓`, Enter, Esc. Prompts off, never forced, results as toasts. |
| `mods/vnh-tabs/` | `~/.config/herdr-app/mods/vnh-tabs/` | Clone of Herdr's `tabs` (0.1.16) with a **Timeline** button after Files and Changes; it toggles the Timeline panel and is highlighted while the panel shows. Opening the Timeline (button, `⌘⇧B` or palette) closes the Files/Changes panel, and closing it reopens that panel if it was open; showing Files or Changes (button, `⌘E`, `⌥A`) while the Timeline shows closes the Timeline instead, so only one right-side view shows; the side panel and the Timeline share one width (dragging either edge sets it for all three: Files, Changes, Timeline); the left sidebar is left alone. **Insights** (`vnh-tabs.insights`, the `insights` toolbar button): opens the Insights tab and hides the right panel and the Timeline; the button again, `Esc` in the dashboard (`vnh-tabs.insights-close`) or the tab's × closes it, returns to the previous tab and brings back what was open. |
| `mods/vnh-prompts/` | `~/.config/herdr-app/mods/vnh-prompts/` | Clone of the `over9k-prompts` Timeline panel without its "Timeline" title (the tab bar's button names it). `place` is `none` so Herdr does not dock an extra copy; the layout places it. |
| `mods/vnh-files/` | `~/.config/herdr-app/mods/vnh-files/` | Clone of Herdr's `files` (0.1.16), the VNH Files panel (`main.js` view, `lib.js` helpers). **Tree** (virtual list, up to 20,000 entries / 1,000 per folder): VS Code style git colors (`U`/`A` green, `M` yellow, `D`/`!` red, folders take the most severe status with `•`), ignored entries dimmed or hidden, sizes, sort (name / type / modification time), expand / collapse all, a **Recent changes** section (git-changed files edited in the last 15 min), drag a row into a terminal to type `@path`, right-click for `vnh-files-menu`. **Filters** (header buttons show on hover): search by name over `git ls-files` (`/` or `⌘F`; an empty box lists recently viewed files), changed files only. **Preview**: syntax-highlighted text with a change ruler, a diff view against HEAD, images, editing (`⌘S` saves, refused if the file changed on disk), a clickable breadcrumb that reveals folders; Markdown opens rendered in `vnh-markdown` (eye / `Space`). **Keys** while the panel has the keyboard: `↑`/`↓` move, `→`/`←` open / close, Enter opens, `Space` quick-looks Markdown, Esc goes back. The folder's name is the title. |
| `karabiner/herdr-hotkey.json` | merged into `~/.config/karabiner/karabiner.json` (selected profile) | Karabiner-Elements rule: `⌘`` ` from any app activates Herdr (`open -b dev.herdr.app`). It replaces macOS's own `⌘`` ` (cycle the windows of the front app). |
| `mods/vnh-worktree-sync/` | `~/.config/herdr-app/mods/vnh-worktree-sync/` | Opens every git worktree in a project's `.worktrees/` folder as a Herdr space (in the background), every 30 s, for the repos of the spaces already open. Herdr's sidebar nests them under their repo. Each worktree is opened once: one you close stays closed. Renders nothing; the VNH layout holds it in a 0 px sidebar block. |
| `mods/vnh-command/` | `~/.config/herdr-app/mods/vnh-command/` | `⌘↩` popup: type any command and Enter runs it in a new tab of the active space, at the focused terminal's repo root (else its folder), through `$SHELL -ic` (aliases, `&&`, pipes work). It also lists the project's `package.json` scripts (the run configurations that used to sit in the sidebar) as `pnpm run <name>` with their commands, package manager from `packageManager` or the lock file: after the history when nothing is typed, ranked by name while typing (starts with, every word, letters in order, then a command match). Empty input lists the history (newest first, with folder and age); typing filters it; `↑`/`↓`, Enter, `⌃D` forgets an entry, Esc. History: shared `vnh.cmd.history`, last 200, deduplicated. |
| `mods/vnh-markdown/` | `~/.config/herdr-app/mods/vnh-markdown/` | A rendered Markdown file in its own tab, one per space: opening another file (or a relative `.md` link) switches that tab to it and renames it (shared `vnh.markdown.open`) instead of adding a tab (`TextView.markdown`, selectable), opened by the eye button the Files panel shows while previewing a `.md`/`.markdown`/`.mdx` file. Re-reads the file every 2 s while the window is active; relative `.md` links open in another such tab, other links in the browser. Text in PragmataPro. Keyboard (Quick Look style): `Space` on a `.md` preview in the Files panel opens it; `Esc` or `Space` in the viewer closes it, returns to the previous tab and gives the keyboard back to the Files panel. |

| `mods/vnh-files-menu/` | `~/.config/herdr-app/mods/vnh-files-menu/` | Right-click menu for Files rows: copy relative / absolute / `@` path, reveal in Finder, open with the default app or VS Code, new terminal here, new file / folder, rename (never overwrites), move to Trash (Finder, so Put Back works). |
| `mods/vnh-spaces/` | `~/.config/herdr-app/mods/vnh-spaces/` | Clone of Herdr's `spaces` (0.1.16) used by the VNH layout's Spaces list. | `mods/vnh-weather/` | `~/.config/herdr-app/mods/vnh-weather/` | Weather at the bottom of the VNH sidebar (the 66 px `weather` block, no border or background of its own), drawn like the sidebar: theme colors, monochrome Lucide icons, two lines. `☁ 17° Cloudy · Hanoi   18° / 15°`, then the next four hours. ## Install

```sh
./install.sh            # mods + status line script
./install.sh --layout   # also the layout + its keys, and switch Herdr to it
./install.sh --karabiner  # also the Cmd+` -> Herdr Karabiner rule (combine flags freely)
```

Existing files are backed up as `<file>.bak-<timestamp>`.

The layout also places mods that are installed separately: `chat-agents`, `gitview`, `new-chat`, `insights` (its toolbar button sits after the tab bar), `filetree` + `file-icons` (the Files panel; `patches/filetree-vnh.patch` adds a ⊙ / ⊘ button and `i` to show or hide git-ignored files and folders, and makes rows draggable into a terminal or an agent input as `@path` like `vnh-files`; a Markdown file opens rendered in `vnh-markdown` from the eye right after its name (brightens under the pointer) or in its preview, or with Space, and Esc or Space there closes the tab and gives the keyboard back to the tree), `better-config` ([munza/herdr-mods](https://github.com/munza/herdr-mods/tree/main/better-config), `⌘⌥,`: every installed mod's settings in one dialog, checked before saving, kept across mod updates, plus a list of installed mods), `walkthrough` ([dmazlum/herdr-walkthrough](https://github.com/dmazlum/herdr-walkthrough), `⌘⇧K`: a diff (uncommitted, staged, branch, commit, PR, last turn) explained step by step by `claude -p` with no tools; its Last turn hooks are in `claude/walkthrough-hooks.json`, merge them into `~/.claude/settings.json` `hooks`), `portal` ([CodeyPacker/herdr-mods](https://github.com/CodeyPacker/herdr-mods/tree/main/portal), `ctrl-shift-u`: every local TCP/UDP port by owning process, favorites, open in the browser, end a process after a confirm; on macOS 14 apply `patches/portal-macos14.patch`, since its `netstat -anv` has no `name:pid` column and the stock parser finds nothing), `run` ([CodeyPacker/herdr-mods](https://github.com/CodeyPacker/herdr-mods/tree/main/run), `ctrl-shift-r` opens it, `ctrl-shift-q` closes a popup; runs the processes a repo declares in `herdr.procs.json` as background terminals, with single-key start / stop / restart / peek), `cloudflare-deploys` ([SaifHarding/herdr-cloudflare](https://github.com/SaifHarding/herdr-cloudflare), the cloud icon at the right of the sidebar's branch row (the `brand-row`); read-only. With wrangler instead of an API token every check starts one node process per project, so set `CF_POLL_SECONDS=300` in `~/.config/cloudflare-deploys/.env`, and `CF_WRANGLER` to a global wrangler if a repo's `node_modules/.bin/wrangler` is broken), `better-changes` ([munza/herdr-mods](https://github.com/munza/herdr-mods/tree/main/better-changes), the Changes panel; set its `mod.json` `place` to `"none"`, or Herdr docks a second copy around the layout and breaks the titlebar). Apply `patches/better-changes-vnh.patch` (`patch -p1 -d ~/.config/herdr-app < patches/better-changes-vnh.patch`) so `Esc` closes its diff tab and returns to the tab you opened the file from, and a Fork-style view dropdown next to Refresh picks a flat list (single column, or multiple columns: name, folder, changes) or folder tree, an inline or side-by-side diff, and fluid or split view staging (Unstaged above, Staged below, each scrolling, with a draggable divider whose position is remembered; drag a file between the two areas to stage or unstage it). Each file row has a checkbox instead of `+` / `−`: ticked is staged, a click stages or unstages. A ✨ button joined to the left of Commit (`⌥S` while the Changes panel shows) writes a Conventional Commits message for the staged diff with the agent CLI running in the space (`claude -p --model haiku`, or `codex exec` for Codex) and fills the message box, which grows with the message from 4 to 10 rows; nothing is committed until you press Commit. Install those first, or Herdr shows empty blocks for them. For the Insights toggle, apply `patches/insights-vnh.patch` to the installed `insights` mod (`patch -p1 -d ~/.config/herdr-app < patches/insights-vnh.patch`): its button calls `vnh-tabs.insights` and `Esc` closes the tab.

The Timeline panel sits in the `work-body` row beside the side panel, so it has the same 8 px inset, rounded frame and bottom (above the status bar) as Files and Changes, and opening it doesn't narrow the tab bar.

## Restore defaults

- In-terminal Claude status line: delete the `exit 0` line under "publish model + limits" in `~/.claude/statusline.sh`. The full two-line status line is still below it.
- Herdr's stock status bar: in the layout, change `"mod": "claude-limits-status"` back to `"mod": "workspace-status"`.
- Herdr's stock layout: `herdr-app do layout.switch '{"name":"main"}'`, or press `ctrl-alt-shift-escape`.

## Notes

- Several Claude Code sessions can run at once. The model and context % shown are from the session that refreshed last; the 5h and 7d limits are account-wide.
- Rate limits arrive only after a session's first API response; until then the previous values are kept.

- The VNH mods share the last focused terminal folder per space (`vnh.lastCwd`, kept by `vnh-tabs`, and by `vnh-files` when it is placed), so mod panes such as the Markdown viewer don't switch the Files panel, run bar, `⌘↩` popup or status bar to the space's starting folder (which can be another project).
- `claude/filetree-hooks.json`: the Claude Code hooks for filetree's activity bridge (reads purple, writes orange, commits green, the Recent tab). Merge its four entries into `~/.claude/settings.json` `hooks` (after any you have); they run `~/.bun/bin/bun` on `mods/filetree/bridge.ts`, print nothing, always exit 0, and append to `~/.local/state/herdr-filetree/activity.jsonl`.
- Performance (audited): third-party panels in the side panel stop reading while hidden (the filetree patch) and catch up when shown; filetree ignores `.git` noise such as fsmonitor cookies, which made it run `git status` at every other tool's pace in repos with `core.fsmonitor=true`; the status bar's git reads pass `-c core.fsmonitor=false`; `patches/cloudflare-deploys-vnh.patch` runs at most 3 wrangler fetches at once (each is a ~260 MB node process). The tab bar and pane headers draw no working spinner: the sidebar's Agents list is the one place that shows it, as a slowly breathing dot (`patches/chat-agents-vnh.patch`, for the separately installed `chat-agents`).
- The walkthrough Last turn hook adds about 0.7 s before a prompt is sent in a large repo (it snapshots the working tree), and 0.3 s when a turn ends.
- `⌘\` (`vnh-tabs.git-push`) pushes with no dialog: the current branch of the repo you work in (the active space's last terminal folder) to its upstream, else to `origin` (or the first remote) with `--set-upstream`, then `git push <remote> --tags`; never forced, `GIT_TERMINAL_PROMPT=0` so a missing login fails instead of hanging; the result is a toast.
- Trackpad pinch anywhere in Herdr, terminals included, runs git on the work folder's repo: pinching the fingers together runs `git pull --ff-only` (`vnh-tabs.git-pull`), spreading them apart pushes the branch and its tags as `⌘\` does (the plist's `HERDR_PINCH_TOGETHER` / `HERDR_PINCH_APART` and `HERDR_PINCH_IN` / `HERDR_PINCH_OUT` change the commands and thresholds without a rebuild; a rebuild needs Accessibility granted again). Mods only see pinches over what they draw, so `gestures/HerdrPinch.swift` (built into `~/Applications/HerdrPinch.app`, signed ad hoc, run by the LaunchAgent `dev.vnh.herdr-pinch`, `./install.sh --gestures`) watches magnify gestures system-wide and acts only while Herdr is frontmost: once per gesture, past a clear pinch (+0.35 / −0.3 of scale), at most every 3 s. Log: `~/Library/Logs/herdr-pinch.log`. Remove: `launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/dev.vnh.herdr-pinch.plist` and delete the plist and binary.
