# herdr-toolkit

Personal customizations for the [Herdr](https://herdr.dev) desktop app.

## What's here

| Path | Installs to | What it does |
|---|---|---|
| `mods/claude-limits-status/` | `~/.config/herdr-app/mods/claude-limits-status/` | Herdr's bottom status bar (clone of `workspace-status` 0.1.16) plus Claude Code's model, usage limits and context window usage next to the agents count: `6 agents │ Opus 5.5 (medium) 17%/5h 3h35m 7%/7d 2d13h 42%/ctx`. Only the percentages are colored (green, yellow ≥ 60 %, red ≥ 85 %). Next to the branch it shows git stats for the focused terminal's folder, zero counts hidden: `⚔` conflicts, `●` staged, `✚` modified, `?` untracked, `↑`/`↓` ahead/behind upstream, `+A/−D` uncommitted lines, `stash N`, `REBASING`/`MERGING` (refreshed on focus change and every 6 s). Then the branch's pull request via `gh pr view`: `#123` (click opens it), CI `✓` pass / `✗` fail / `●` pending with its wall-clock time (earliest check start to latest finish; while running, time so far, refreshed every 10 s), `draft`/`merged`/`closed`, `approved`/`changes requested`; asked at most once a minute per branch, hidden when the branch has no PR or `gh` is missing. At the right, where Herdr shows the palette hint, prices: `BTC $63,175 +0.0%  ETH $1,786 +0.9%  Gold $3,677 −1.5%` (24 h change green / red) from CoinGecko's public `simple/price` API (gold is Tether Gold, one token per troy ounce), one GET every 2 min while the window is active, no key; click refreshes. `⌘⇧P` still opens the palette. |
| `mods/vnh-chrome/` | `~/.config/herdr-app/mods/vnh-chrome/` | Clone of Herdr's `workspace-chrome` (0.1.16). The sidebar's top row is a JetBrains style run bar instead of the logo, search (`⌘P`) and sidebar toggle (`⌘B`): `📦 pnpm run dev ▾` and `▶`. It reads `package.json` scripts at the focused terminal's repo root only (the folder itself outside git); the package manager comes from `packageManager`, else the lock file, else npm. `▶` runs the selected script in a new tab at that folder; while it runs a red `■` stops it like JetBrains (SIGINT to its process group, SIGTERM after 3 s; the tab and output stay). A run records its pid in `~/.cache/vnh-run/`. The pill opens `vnh-run-menu` flush with its left edge. The choice is remembered per project; no `package.json` means an empty row. |
| `mods/vnh-run-menu/` | `~/.config/herdr-app/mods/vnh-run-menu/` | The run configurations popup: search, scripts A–Z with their commands, `↑`/`↓`, Enter or click selects, `▶` on a row runs it, Esc closes. |
| `mods/vnh-tabs/` | `~/.config/herdr-app/mods/vnh-tabs/` | Clone of Herdr's `tabs` (0.1.16) with a **Git** button after Files and Changes (shown when the layout's panel holds a `graph` block, the `git-graph` mod) and a **Timeline** button; it toggles the Timeline panel and is highlighted while the panel shows. Opening the Timeline (button, `⌘⇧B` or palette) closes the Files/Changes panel, and closing it reopens that panel if it was open; the left sidebar is left alone. **Insights** (`vnh-tabs.insights`, the `insights` toolbar button): opens the Insights tab and hides the right panel and the Timeline; the button again, `Esc` in the dashboard (`vnh-tabs.insights-close`) or the tab's × closes it, returns to the previous tab and brings back what was open. |
| `mods/vnh-prompts/` | `~/.config/herdr-app/mods/vnh-prompts/` | Clone of the `over9k-prompts` Timeline panel without its "Timeline" title (the tab bar's button names it). `place` is `none` so Herdr does not dock an extra copy; the layout places it. |
| `mods/vnh-files/` | `~/.config/herdr-app/mods/vnh-files/` | Clone of Herdr's `files` (0.1.16), the VNH Files panel (`main.js` view, `lib.js` helpers). **Tree** (virtual list, up to 20,000 entries / 1,000 per folder): VS Code style git colors (`U`/`A` green, `M` yellow, `D`/`!` red, folders take the most severe status with `•`), ignored entries dimmed or hidden, sizes, sort (name / type / modification time), expand / collapse all, a **Recent changes** section (git-changed files edited in the last 15 min), drag a row into a terminal to type `@path`, right-click for `vnh-files-menu`. **Filters** (header buttons show on hover): search by name over `git ls-files` (`/` or `⌘F`; an empty box lists recently viewed files), changed files only. **Preview**: syntax-highlighted text with a change ruler, a diff view against HEAD, images, editing (`⌘S` saves, refused if the file changed on disk), a clickable breadcrumb that reveals folders; Markdown opens rendered in `vnh-markdown` (eye / `Space`). **Keys** while the panel has the keyboard: `↑`/`↓` move, `→`/`←` open / close, Enter opens, `Space` quick-looks Markdown, Esc goes back. The folder's name is the title. |
| `karabiner/herdr-hotkey.json` | merged into `~/.config/karabiner/karabiner.json` (selected profile) | Karabiner-Elements rule: `⌘`` ` from any app activates Herdr (`open -b dev.herdr.app`). It replaces macOS's own `⌘`` ` (cycle the windows of the front app). |
| `mods/vnh-worktree-sync/` | `~/.config/herdr-app/mods/vnh-worktree-sync/` | Opens every git worktree in a project's `.worktrees/` folder as a Herdr space (in the background), every 30 s, for the repos of the spaces already open. Herdr's sidebar nests them under their repo. Each worktree is opened once: one you close stays closed. Renders nothing; the VNH layout holds it in a 0 px sidebar block. |
| `mods/vnh-command/` | `~/.config/herdr-app/mods/vnh-command/` | `⌘↩` popup: type any command and Enter runs it in a new tab of the active space, at the focused terminal's repo root (else its folder), through `$SHELL -ic` (aliases, `&&`, pipes work). Empty input lists the history (newest first, with folder and age); typing filters it; `↑`/`↓`, Enter, `⌃D` forgets an entry, Esc. History: shared `vnh.cmd.history`, last 200, deduplicated. |
| `mods/vnh-markdown/` | `~/.config/herdr-app/mods/vnh-markdown/` | A rendered Markdown file in its own tab (`TextView.markdown`, selectable), opened by the eye button the Files panel shows while previewing a `.md`/`.markdown`/`.mdx` file. Re-reads the file every 2 s while the window is active; relative `.md` links open in another such tab, other links in the browser. Text in PragmataPro. Keyboard (Quick Look style): `Space` on a `.md` preview in the Files panel opens it; `Esc` or `Space` in the viewer closes it, returns to the previous tab and gives the keyboard back to the Files panel. |
| `mods/vnh-pane/` | `~/.config/herdr-app/mods/vnh-pane/` | Clone of Herdr's `pane` header (0.1.16) used by the VNH layout; shows readable titles for VNH mod panes (`vnh-markdown` → "Markdown Viewer"). |
| `mods/vnh-files-menu/` | `~/.config/herdr-app/mods/vnh-files-menu/` | Right-click menu for Files rows: copy relative / absolute / `@` path, reveal in Finder, open with the default app or VS Code, new terminal here, new file / folder, rename (never overwrites), move to Trash (Finder, so Put Back works). |

| `mods/vnh-weather/` | `~/.config/herdr-app/mods/vnh-weather/` | Weather at the bottom of the VNH sidebar (the 66 px `weather` block, no border or background of its own), drawn like the sidebar: theme colors, monochrome Lucide icons, two lines. `☁ 17° Cloudy · Hanoi   18° / 15°`, then the next four hours. The tooltip adds feels-like, humidity, wind and the next three days; a click opens yr.no. | `claude/statusline.sh` | `~/.claude/statusline.sh` | Claude Code status line command. It publishes model, effort, 5h/7d usage, reset times and context % to `~/.cache/claude-statusline/limits.json` (read by the mod) and prints nothing, so the in-terminal status line is hidden. |
| `layouts/VNH.json` | `~/.config/herdr-app/layouts/VNH.json` | The **VNH** layout, based on Herdr's `main`: status bar uses `claude-limits-status`, the sidebar's top row uses `vnh-chrome`, the tab bar uses `vnh-tabs`, the Changes panel uses `better-changes` (`gitview` before; put it back in the `changes` block to return), the Files panel uses `filetree` ([cybertron288/herdr-mods](https://github.com/cybertron288/herdr-mods/tree/main/filetree), installed separately with its `file-icons`; `vnh-files` stays in this repo, put `"mod": "vnh-files"` back in the `files` block to use it), and the sidebar footer (Settings / Add machine) is removed. ## Install

```sh
./install.sh            # mods + status line script
./install.sh --layout   # also the layout + its keys, and switch Herdr to it
./install.sh --karabiner  # also the Cmd+` -> Herdr Karabiner rule (combine flags freely)
```

Existing files are backed up as `<file>.bak-<timestamp>`.

The layout also places mods that are installed separately: `chat-agents`, `gitview`, `new-chat`, `insights` (its toolbar button sits after the tab bar), `git-graph` ([rabeeh-ta/herdr-git-graph](https://github.com/rabeeh-ta/herdr-git-graph), the panel's `graph` block; `patches/git-graph-vnh.patch` makes the branch chip a searchable branch picker (local by latest commit, then untracked remote branches), adds a Push button and `⌘\\` with a "Push tags too" option (`git push <remote> --tags`, never forced; the branch search takes words in any order or letters in order, e.g. `rspw`; an author box in the toolbar filters the history by email or name through `git log -i -F --author`) (via `vnh-tabs.git-push`, which shows the panel first), and idles while hidden), `filetree` + `file-icons` (the Files panel; `patches/filetree-vnh.patch` adds a ⊙ / ⊘ button and `i` to show or hide git-ignored files and folders, and makes rows draggable into a terminal or an agent input as `@path` like `vnh-files`), `better-config` ([munza/herdr-mods](https://github.com/munza/herdr-mods/tree/main/better-config), `⌘⌥,`: every installed mod's settings in one dialog, checked before saving, kept across mod updates, plus a list of installed mods), `walkthrough` ([dmazlum/herdr-walkthrough](https://github.com/dmazlum/herdr-walkthrough), `⌘⇧K`: a diff (uncommitted, staged, branch, commit, PR, last turn) explained step by step by `claude -p` with no tools; its Last turn hooks are in `claude/walkthrough-hooks.json`, merge them into `~/.claude/settings.json` `hooks`), `portal` ([CodeyPacker/herdr-mods](https://github.com/CodeyPacker/herdr-mods/tree/main/portal), `ctrl-shift-u`: every local TCP/UDP port by owning process, favorites, open in the browser, end a process after a confirm; on macOS 14 apply `patches/portal-macos14.patch`, since its `netstat -anv` has no `name:pid` column and the stock parser finds nothing), `run` ([CodeyPacker/herdr-mods](https://github.com/CodeyPacker/herdr-mods/tree/main/run), `ctrl-shift-r` opens it, `ctrl-shift-q` closes a popup; runs the processes a repo declares in `herdr.procs.json` as background terminals, with single-key start / stop / restart / peek), `cloudflare-deploys` ([SaifHarding/herdr-cloudflare](https://github.com/SaifHarding/herdr-cloudflare), the cloud icon after Insights in the tab bar row; read-only. With wrangler instead of an API token every check starts one node process per project, so set `CF_POLL_SECONDS=300` in `~/.config/cloudflare-deploys/.env`, and `CF_WRANGLER` to a global wrangler if a repo's `node_modules/.bin/wrangler` is broken), `better-changes` ([munza/herdr-mods](https://github.com/munza/herdr-mods/tree/main/better-changes), the Changes panel; set its `mod.json` `place` to `"none"`, or Herdr docks a second copy around the layout and breaks the titlebar). Apply `patches/better-changes-vnh.patch` (`patch -p1 -d ~/.config/herdr-app < patches/better-changes-vnh.patch`) so `Esc` closes its diff tab and returns to the tab you opened the file from, and a Fork-style view dropdown next to Refresh picks a flat list (single column, or multiple columns: name, folder, changes) or folder tree, an inline or side-by-side diff, and fluid or split view staging (Unstaged above, Staged below, each scrolling, with a draggable divider whose position is remembered; drag a file between the two areas to stage or unstage it). Each file row has a checkbox instead of `+` / `−`: ticked is staged, a click stages or unstages. A ✨ button joined to the left of Commit (`⌥S` while the Changes panel shows) writes a Conventional Commits message for the staged diff with the agent CLI running in the space (`claude -p --model haiku`, or `codex exec` for Codex) and fills the message box, which grows with the message from 4 to 10 rows; nothing is committed until you press Commit. Install those first, or Herdr shows empty blocks for them. For the Insights toggle, apply `patches/insights-vnh.patch` to the installed `insights` mod (`patch -p1 -d ~/.config/herdr-app < patches/insights-vnh.patch`): its button calls `vnh-tabs.insights` and `Esc` closes the tab.

The Timeline panel sits in a `work-split` row below the tab bar (with the work area and status bar), so opening it no longer narrows the tab bar; the status bar then ends where the Timeline starts.

## Restore defaults

- In-terminal Claude status line: delete the `exit 0` line under "publish model + limits" in `~/.claude/statusline.sh`. The full two-line status line is still below it.
- Herdr's stock status bar: in the layout, change `"mod": "claude-limits-status"` back to `"mod": "workspace-status"`.
- Herdr's stock layout: `herdr-app do layout.switch '{"name":"main"}'`, or press `ctrl-alt-shift-escape`.

## Notes

- Several Claude Code sessions can run at once. The model and context % shown are from the session that refreshed last; the 5h and 7d limits are account-wide.
- Rate limits arrive only after a session's first API response; until then the previous values are kept.

- The VNH mods share the last focused terminal folder per space (`vnh.lastCwd`, kept by `vnh-tabs`, and by `vnh-files` when it is placed), so mod panes such as the Markdown viewer don't switch the Files panel, run bar, `⌘↩` popup or status bar to the space's starting folder (which can be another project).
- `claude/filetree-hooks.json`: the Claude Code hooks for filetree's activity bridge (reads purple, writes orange, commits green, the Recent tab). Merge its four entries into `~/.claude/settings.json` `hooks` (after any you have); they run `~/.bun/bin/bun` on `mods/filetree/bridge.ts`, print nothing, always exit 0, and append to `~/.local/state/herdr-filetree/activity.jsonl`.
- Performance (audited): third-party panels in the side panel stop reading while hidden (`patches/git-graph-vnh.patch`, the filetree patch) and catch up when shown; filetree ignores `.git` noise such as fsmonitor cookies, which made it run `git status` at every other tool's pace in repos with `core.fsmonitor=true`; the status bar's git reads pass `-c core.fsmonitor=false`; `patches/cloudflare-deploys-vnh.patch` runs at most 3 wrangler fetches at once (each is a ~260 MB node process). The tab bar and pane headers draw no working spinner: the sidebar's Agents list is the one place that shows it, as a slowly breathing dot (`patches/chat-agents-vnh.patch`, for the separately installed `chat-agents`).
- The walkthrough Last turn hook adds about 0.7 s before a prompt is sent in a large repo (it snapshots the working tree), and 0.3 s when a turn ends.
